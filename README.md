### Projekte

**[Videoflix](https://github.com/KevinHaseDev/Videoflix)**: Backend einer Streaming-Plattform. Django REST Framework, JWT in HttpOnly-Cookies, PostgreSQL. Hochgeladene Videos werden mit FFmpeg in HLS-Streams umgewandelt, das läuft über eine Redis Queue im Hintergrund, damit der Upload-Request nicht blockiert. Der ganze Stack liegt in Docker Compose.

**[Quizly](https://github.com/KevinHaseDev/Quizly)**: Macht aus einem YouTube-Video ein Quiz. yt-dlp holt das Audio, Whisper transkribiert es lokal, Gemini Flash baut daraus zehn Multiple-Choice-Fragen. Django REST API mit JWT.

**[Coderr](https://github.com/KevinHaseDev/Coderr)**: REST-API für einen Marktplatz zwischen Anbietern und Kunden. Getrennte Django-Apps für Profile, Angebote, Bestellungen und Bewertungen, Token-Auth über DRF.

**[Join](https://github.com/KevinHaseDev/Join)**: Task-Management nach Kanban-Prinzip für mehrere Nutzer, gebaut mit Angular und SCSS.

**[KanMind](https://github.com/KevinHaseDev/KanMind)**: Kanban-Backend mit Boards, Tasks und Kommentaren als REST-API.

**[El Pollo Loco](https://github.com/KevinHaseDev/El-Pollo-Loco)**: Jump-and-Run im Browser, reines JavaScript auf einem Canvas, objektorientiert aufgebaut. Ohne Framework, ohne Engine.

**[Portfolio](https://github.com/KevinHaseDev/Portfolio)**: Meine Projektseite, [portfolio.kevin-hase.de](https://portfolio.kevin-hase.de). Angular.
